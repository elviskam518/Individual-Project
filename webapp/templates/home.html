Project Overview

This web application provides a local interface for running the fairness analysis and model evaluation pipeline developed for this project.

  • Intermediate fairness analysis using bias_analysis.py
  • Baseline MLP and standalone adversarial debiasing from adversarial_baselines.py
  • Fair CVAE training and evaluation from fair_cvae.py
  • Latent-space visualisation from latent_visualisation.py
  • Background job execution with live status, progress, and logs

Use the navigation above to access the interactive demo, completed results, and intermediate fairness analysis pages.
